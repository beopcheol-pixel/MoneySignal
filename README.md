# MoneySignal

Telegram-style economic signal app MVP.

## Tech Stack
- **Frontend**: React Native (Expo)
- **Backend**: Node.js + Express
- **Database**: SQLite
- **AI**: OpenAI-compatible API

## Features
1. Signals feed (max 3 per day)
2. Channels (read-only posts)
3. AI Coach chat
4. Groups (messages + weekly check-in)
5. User financial profile

## Quick Start

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```
